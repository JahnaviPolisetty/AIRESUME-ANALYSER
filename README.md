🚀 Overview

The AI Resume Screener simplifies and speeds up the hiring and job preparation process using Artificial Intelligence.
It accepts a resume document and a job description, then intelligently evaluates the resume’s relevance to the role.

It offers two distinct user modes:

👨‍💼 Recruiter Mode

Designed for companies and HR teams.

Upload a candidate’s resume and a job description.

Instantly receive:

Resume Summary

AI-based Match Score (out of 100)

👩‍💻 Job Seeker Mode

Designed for individuals applying for jobs.

Upload your own resume and a target job description.

Instantly receive:

AI-based Match Score (out of 100)

Detailed Resume Summary

Personalized Suggestions to improve your resume

⚙️ Key Features

✅ Two modes — Recruiter & Job Seeker
✅ AI-generated Resume Summary
✅ Resume–Job Description Match Scoring
✅ Resume Improvement Suggestions
✅ Fast Response (Results in seconds)
✅ Clean & Interactive UI
✅ Built using Supabase (Frontend + AI Edge Functions Backend Integration)

🧠 How It Works

Choose a user type: Recruiter or Job Seeker

Upload your resume (.pdf) and job description (.txt or pasted)

Click Analyze

Get:

Recruiter → Score + Summary

Job Seeker → Score + Summary + Improvement Suggestions
